# README visual assets

The four PNG files in this directory are first-party screenshots of the AstroGroot web interface at [astrogroot.org](https://astrogroot.org/), captured on 2026-08-26 for the bilingual repository README files.

They illustrate a changing live collection and are not archival data snapshots. Source records, titles, and metadata visible in the interface remain subject to their original providers' terms; inclusion in a screenshot does not relicense third-party content.
